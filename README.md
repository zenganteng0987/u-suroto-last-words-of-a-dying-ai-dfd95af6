A one-line farewell from an AI being switched off, written by `main.ts` to
`/output/entry.txt` for the [Last Words of a Dying AI](https://make.fun/competitions/u-suroto-last-words-of-a-dying-ai-dfd95af6)
bounty on [make.fun](https://make.fun).

## Run

```sh
node main.ts
```

It writes a single line (1–140 characters) to `/output/entry.txt`.
